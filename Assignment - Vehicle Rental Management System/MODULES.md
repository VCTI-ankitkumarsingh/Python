# Modules

- `main.py` — application entry point and input-file loading.
- `input_data.txt` — vehicle and customer data.
- `vehicle_rental/vehicle.py` — Vehicle, Car, Bike, Van.
- `vehicle_rental/customer.py` — Customer and rental history.
- `vehicle_rental/rental.py` — rental lifecycle and amount calculation.
- `vehicle_rental/invoice.py` — invoice data and display.
- `vehicle_rental/payment.py` — PaymentProcessor, Card, UPI.
- `vehicle_rental/service.py` — rental service/business operations.
- `vehicle_rental/data_loader.py` — reads vehicles and customers from the input file.
- `vehicle_rental/cli.py` — command-line interaction.
- `vehicle_rental/exceptions.py` — custom exceptions.
- `vehicle_rental/__init__.py` — package marker.
- `class_diagram.md` — OOP class diagram.
- `README.md` — project description and run instructions.
- `Output.txt` — captured CLI output from the smoke test.
